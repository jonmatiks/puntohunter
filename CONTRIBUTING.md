# Contributing to PuntoHunter

Bug reports, ideas, and pull requests are welcome. Before you start, read:

* [Contributing](docs/guide/contributing.md): reporting a bug, proposing a change, and what a change needs
  before it is merged. For anything beyond a small fix, open an issue first.
* [Development](docs/guide/development.md): building, running a pool on regtest, and the tests.

Report a vulnerability privately, through the repository's Security tab, as [SECURITY.md](SECURITY.md)
describes, never in an issue.
